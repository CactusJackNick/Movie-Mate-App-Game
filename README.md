Architecture Overview

Movie Mate is built on a highly modular, event-driven architecture using a hybrid Mediator and MVC/MVP pattern. At the top level, a centralized UINavigationMediator manages the application's state, handling global screen transitions and blocking UI during asynchronous loading. Individual screens (such as the Main Menu, Game, and Movie Details) act as localized feature modules governed by their respective Panels (e.g., GamePanel). Inheriting from ABaseUIMediatorComponent, these Panels serve as the composition root for their screen, responsible for instantiating dependencies and executing entry/exit animations. To ensure strict separation of concerns, the Panels wire "Dumb" UI Views to logic-heavy Controllers. The Controllers process user input and game rules, delegating all external data fetching, filtering, and validation to a dedicated, interface-based Service Layer that interfaces with the TMDB API.
